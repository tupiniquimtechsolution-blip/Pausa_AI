# 00_RAW_CHATS

Camada para preservar a sequência original de conversas **somente após sanitização**.

Não versionar exports privados brutos quando contiverem PII, dados de saúde/bem-estar, credenciais, cookies, tokens ou outros dados inadequados para um repositório público.

Cada arquivo deve registrar origem, data, status de sanitização e, quando possível, o `CHAT-ID` correspondente.
